# Umliva public website

Static GitHub Pages site for Umliva – Nebenkosten prüfen. It contains public product principles, privacy positioning, verification philosophy, roadmap, sanitized architecture diagrams and bounded German-language Ratgeber pages for real billing-check search intents.

Run `node verify-site.mjs` for the deterministic metadata, link, robots, sitemap and Mermaid-reference check. Production claims remain bounded by the application proof status; the site does not claim Play availability or verified automatic OCR before those gates pass.
